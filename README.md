# Pokémon Type Checker

Type in a Pokémon and see its typing plus its weaknesses, resistances and immunities. You can also pick one or two types by hand.

It's a static PWA with no build step: plain HTML, CSS and JS. It works offline once loaded.

## Install on your phone
1. Enable GitHub Pages: **Settings → Pages → Deploy from a branch → `main` / root**.
2. Open the Pages URL in Safari (iOS) or Chrome (Android).
3. Share → **Add to Home Screen**.

When you update the app, bump `CACHE` in `sw.js` so installed copies pick up the change.
